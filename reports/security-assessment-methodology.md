# Security Assessment Methodology

This portfolio follows a structured workflow designed for authorized security assessments and investigations.

**Authorization & Scope → Discovery → Assessment → Evidence Collection → Analysis → Reporting → Remediation → Retesting**

## Authorization & Scope
Define the systems, applications, accounts, testing windows and activities that are explicitly authorized.

## Discovery
Identify relevant assets, hosts, services, technologies and exposed attack surface.

## Assessment
Perform appropriate security checks using tools such as Nmap, Burp Suite, Wireshark and Suricata within the approved scope.

## Evidence Collection
Capture relevant logs, packets, alerts, screenshots and other technical evidence.

## Analysis
Validate findings, correlate evidence and determine likely security impact.

## Reporting
Document the executive summary, scope, methodology, findings, evidence, risk/impact, IOCs where applicable, and recommended remediation.

## Remediation & Retesting
Provide practical hardening recommendations and, where applicable, validate that reported issues have been addressed.

> All examples in this repository are from controlled or simulated environments. No unauthorized systems are tested.

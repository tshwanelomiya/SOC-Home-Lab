# Suricata IDS & Detection Engineering

## Objective

Deploy and configure Suricata as a network intrusion detection system and develop custom detection rules for controlled security activity.

## Environment

- Kali Linux
- Suricata 8.0.5
- Nmap
- Wireshark
- TCPDump
- OWASP Juice Shop

## Work Performed

- Configured Suricata using AF_PACKET.
- Created custom rules for Nmap SYN scanning.
- Created a custom rule for XSS-related HTTP traffic.
- Investigated duplicate signature/SID errors.
- Validated generated alerts through Suricata logs and `fast.log`.
- Correlated network traffic with detection events.

# Netcat HTTP Protocol Analysis

## Objective

Understand HTTP communication at the TCP level by manually establishing connections and constructing HTTP requests.

## Work Performed

- Established TCP connections with Netcat.
- Constructed HTTP GET requests using `printf`.
- Examined server responses.
- Investigated service and port differences.
- Documented the relationship between TCP ports and application services.

## Security Skills Demonstrated

Netcat | TCP | HTTP | Command Line | Network Troubleshooting

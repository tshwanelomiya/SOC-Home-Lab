# OWASP Juice Shop Web Application Security Assessment

## Objective

Perform controlled web application security testing against OWASP Juice Shop and document how application activity appears in HTTP traffic.

## Work Performed

- Identified application functionality for testing.
- Intercepted HTTP requests with Burp Suite.
- Examined requests and responses.
- Used Burp Repeater to modify and replay requests.
- Tested XSS functionality using controlled payloads.
- Captured related traffic in Wireshark.
- Developed Suricata detection logic for observed activity.
- Documented findings and security recommendations.

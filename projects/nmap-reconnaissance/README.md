# Network Reconnaissance & Service Enumeration

## Objective

Identify hosts, ports, services, and potential attack surface within a controlled laboratory network.

## Work Performed

- Performed host discovery.
- Conducted port and service scanning.
- Identified open, closed, and filtered ports.
- Investigated exposed services.
- Documented reconnaissance results.
- Used findings to guide subsequent security testing.

## Security Skills Demonstrated

Nmap | Network Reconnaissance | Port Scanning | Service Enumeration | Attack Surface Analysis

# Wireshark Network Traffic Analysis

## Objective
Capture and analyze network traffic generated by controlled web application security testing and identify security-relevant communications.

## Work Performed
- Captured traffic using Wireshark and TCPDump.
- Inspected TCP connections and HTTP requests.
- Applied packet filters to isolate relevant traffic.
- Examined client/server communication.
- Investigated traffic associated with controlled XSS testing.
- Compared packet observations with IDS detection activity.

## Security Skills Demonstrated
Wireshark | TCPDump | Packet Analysis | HTTP Analysis | Network Investigation

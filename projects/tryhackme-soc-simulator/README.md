## What I Practised

During the simulation, I:

1. Reviewed incoming security alerts.
2. Examined the information associated with each alert.
3. Investigated the activity before assigning a verdict.
4. Distinguished legitimate activity from suspicious or malicious activity.
5. Classified alerts as True Positive or False Positive.
6. Documented investigation reasoning in case reports.
7. Identified alerts requiring escalation.
8. Completed the scenario with **100% accuracy**.

TryHackMe describes SOC SIM as a simulated SOC environment where analysts triage alerts, distinguish true and false positives, write case reports, and receive performance feedback. 

## Why This Matters for SOC Work

The exercise demonstrates a fundamental L1 SOC capability: **an alert is not automatically an incident**. The analyst must investigate the available evidence, determine whether the activity is genuinely suspicious, document the reasoning, and escalate when appropriate.

This complements the hands-on network and detection work in this portfolio, particularly:

- Suricata IDS alert generation
- Wireshark network traffic analysis
- Nmap reconnaissance
- Phishing investigation
- Incident reporting
